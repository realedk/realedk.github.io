GETTING STARTED

Make yourself at home.

  1. Download and open the ZIP archive.
  2. Drag Layout Manager.app into your Applications folder.
  3. Open Layout Manager and create a template or blank project.

This build is not notarized. macOS may ask you to approve it in System Settings → Privacy & Security. Only approve a download you trust.

A signed IPA has not been added to this release yet.

Once available, install it using the distribution method supplied with that build. Downloading an IPA in Safari alone does not install it.

The Mac, iPhone, and iPad apps use compatible .layout.json project files. Transfer projects through Files, AirDrop, or iCloud Drive.
